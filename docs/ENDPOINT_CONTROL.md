# RM65 末端控制预览

## 操作方式

- **移动夹爪**：保持当前朝向，控制末端沿选定参考坐标系的 X/Y/Z 方向移动。由控制器协调六个关节。
- **按住移动**：按下方向按钮开始连续示教，松开、触控取消或失去指针捕获后停止。一次只接受一个操作指针。
- **1 / 5 / 10 mm**：按下方向按钮发送一次固定距离步进；手指松开后继续完成这段有限运动，到位后恢复按钮。点击“立即停止”可中断。
- **调整朝向**：沿参考坐标系的 RX/RY/RZ 轴按住旋转。
- **关节调整**：保留六轴独立点动，用于构型调整和退出限位保护区。

## 坐标模式和控制点

工作方向的按钮映射为前移 +X、后移 −X、左移 +Y、右移 −Y、上升 +Z、下降 −Z。“前、左、上”是界面中的方向约定，实际方向取决于当前工作坐标系的标定，与手机朝向无关。

夹爪方向的 X/Y 是工具坐标轴的平移，前进/后退沿工具 ±Z。使用前必须确认工具轴与夹爪的对应关系。连接时读取 `get_teach_frame`；切换时先等待 `set_teach_frame` 成功响应，再读取 `get_teach_frame` 确认。确认完成前禁止末端移动。坐标模式反馈超过 12 秒未更新也会阻止末端运动。

运动围绕控制器当前工具坐标系的控制点进行。工具为 `Arm_Tip` 时通常表示法兰末端；要把抓取中心作为控制点，需要在控制器中标定并选中对应的工具坐标系。本次没有自动改写工具标定。

## 步进与停止

`RobotBridge.stepPosition(axis, direction, distanceMm, speed)` 调用官方 `set_pos_step`；毫米乘 1000 转成协议中的整数距离，1 mm 对应 `step=1000`。

步进完成要同时满足命令成功接收、机械臂到位反馈、反馈之后的新位姿帧，并核对实际位移长度。带有非零 `device` 的外设到位通知不会解除步进状态。步进期间禁止重复移动、回零、夹爪命令和启动动作回放。15 秒内未得到有效到位反馈会发送缓停。步进主动中止或失败会请求停止并关闭连接，未确认路点不记录；连续示教松手使用 `set_stop_teach`。设备未知的完成通知不接受。坐标切换 5 秒未确认时关闭连接。

保留原有实际关节限位、软件范围、提前停止保护、状态超时检查。进入任一关节保护区后禁止末端移动，可在关节页向远离限位方向退回。

## 预览

`index.html?preview=1` 为本地模拟入口。预览脚本只有在明确指定参数且没有 Android `RobotBridge` 时才运行。标准入口和 Android App 不会隐式启用模拟。预览使用初版的 RM65 URDF 变换和数值求解更新示意骨架，供交互体验；实体机械臂的运动由控制器执行。

浏览器预览涵盖移动、毫米步进、坐标切换、朝向、关节和夹爪开口，在预览中不录制实机轨迹。Android 中使用合并后的正式动作逻辑。默认三栏横屏布局；窄竖屏按顺序排列面板以便在侧边浏览器查看。

## 合并版本

当前工程已经合并 1.13.2 的回放、网络、拖动保存与夹爪修复，并包含 IP 设置修复。正式包名为 `com.realman.rm65webview`，版本 1.14.0。详见 [合并记录](MERGE_ENDPOINT.md)。下方为原预览分支的验证历史，合并版验证结果以合并记录为准。

## 验证记录

- 全部 Android Kotlin 源码通过 Android API 35 的类型编译。
- Kotlin JUnit：17 项通过，含协议单位、坐标反馈解析、旧到位通知、外设通知、位姿新鲜度、步进超时与重复发送保护。
- Node：12 项通过，含动作标签回归、指针所有权、触控取消、步进释放、重复步进、坐标模式未确认、限位刷新和预览桥隔离。
- 浏览器 844×390 横屏：六方向、坐标模式、步进选项与固定停止按钮显示完整。
- 模拟前移 5 mm：X 由 −413.13 mm 变为 −408.13 mm，Y/Z 与三个朝向读数保持不变。
- 模拟按住前移并松开：读数变化，随后运动状态显示“静止”。

没有连接实体机械臂；控制器版本、工具控制点和运动行为仍需实机确认。当前合并版已经保留正式版动作修复；尚需实体机械臂验收。

## 构建

使用 Android Studio 或 `./gradlew testDebugUnitTest assembleDebug` 构建。合并版 APK 输出为 `app/build/outputs/apk/debug/app-debug.apk`，使用正式包名和版本配置。保留上级目录的 `.android-signing/rm65-debug.keystore` 可复用当前电脑安装签名。独立预览分支的手工打包脚本不用于此合并版。

官方接口依据：[瑞尔曼运动指令集](https://develop.realman-robotics.com/robot/json/motionConfig/)。

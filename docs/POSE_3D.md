# 1.15.0 三维姿态预览

将原二维骨架替换为离线 RM65-6F 实体模型，根据控制器回传的六轴角度显示姿态。单指拖动画布旋转观察角度，双指或滚轮缩放；右上提供复位视角、正视、俯视和缩放按钮。“复位视角”只改变相机，不是机械臂回零。

画面左上显示实时、等待、未连接或最后姿态。启动未收到数据时显示零位示意，不模拟机械臂状态。模型不包含现场夹爪和障碍物，详见 [模型来源](RM65_MODEL_SOURCE.md)。不能使用 WebGL2 的设备会显示“兼容姿态视图”。

控制协议、手动松手停止、动作回放、夹爪完成确认、IP 保存和动作数据格式不变。3D 模块只接收角度，不发送机械臂命令；后台不持续渲染，重复关节帧不重绘。

验证：72 个 Kotlin 单元测试、34 个 Node 测试通过，APK 构建成功。新增检查包括实体网格尺寸、混合六轴角度的 URDF 层级与法兰方向、非法数据保留、触摸取消/捕获丢失、双指缩放、过期标签，以及所有脚本离线加载。安卓实机显示与安装记录见工程上级 `device-backup-20261016/pose3d-1.15.0/`；未执行实体机械臂运动测试。

2026-10-16 已在 RM100（Android 12）覆盖安装 1.15.0 / versionCode 24。实机截图确认显示实体 3D 模型、地面网格和视角按钮，未进入兼容视图；当前保持未连接，画面正确标注“未连接 · 零位示意”。更新前后全部原有设置值一致，保留 3 个动作及 `192.168.33.80:8080` 地址。启动未发现应用崩溃或未捕获的脚本异常。触摸手势通过单元测试验证，尚未做实机手势自动化测试。

1.15.3 增加随姿态及相机更新的 J1～J6 标签、彩色原点及引线。绿色为 J2/J3/J5 弯曲，蓝色为 J1/J4/J6 旋转。标签无触摸操作，重叠时错开显示。

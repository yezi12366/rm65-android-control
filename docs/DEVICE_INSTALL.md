当前安装签名密钥保存在工程上级目录 `.android-signing/rm65-debug.keystore`。本地工程构建时会在此文件存在时复用它，便于以后直接覆盖更新。请保留该文件；源码 ZIP 不包含私钥，在其他电脑上使用另一密钥构建会再次遇到签名不一致。

更新后的应用仍需由用户点击“连接机械臂”。建议低速验证路点、夹爪完成等待和重复关闭录制；再次中断时使用“复制中断原因”保存诊断。

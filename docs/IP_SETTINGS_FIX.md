# 1.13.3 IP 设置修复

2026-10-16 修复以下问题：编辑 IP 后切到端口框或点击保存，原生状态刷新会覆盖输入；“保存设置”只保存了安全配置，没有持久化 IP 和端口。连接状态下输入框本身也被禁用，旧界面没有设置页内的断开入口。

新版在设置页打开期间保留 IP/端口草稿，顶部地址仍显示已保存的地址；点击保存后通过 `RobotBridge.saveConnectionSettings(host, port)` 写入 SharedPreferences，收到 `connection_settings_saved` 成功事件后关闭设置。失败时保留输入并显示原因，取消时不写入新地址。IP 键盘改为文本输入，方便输入多个句点。

已连接时先点击“断开后修改地址”，等待断开后编辑并保存，再点击“连接机械臂”。保存操作不会自动连接或发送运动指令。

默认地址按当前设备设为 `192.168.33.80:8080`。首次启动会将旧默认 `192.168.1.18` 迁移一次，其他已保存地址保留；之后用户保存的地址不会再次被迁移覆盖。

正式包名不变，版本为 1.13.3（versionCode 21）。已覆盖更新至 RM100 遥控器，安装前后原有设置文件逐字节一致。旧动作库随应用数据保留；备份位于工程上级目录 `device-backup-20261016/`。

验证：Gradle APK 构建成功，55 个 Kotlin 单元测试、9 个 Node 测试及 JavaScript 语法检查通过。新增 6 项设置测试覆盖状态刷新、保存确认、取消、原生拒绝、连接时断开入口和端口校验。

同一修复已同步到 `RM65_Merged_Control` 的 1.14.0 合并版。末端预览分支的测试版由另一个会话维护，包名和正式版不同。

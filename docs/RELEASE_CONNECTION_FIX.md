# 1.15.3 松手保持连接与界面调整

1.15.2 对联动和复位的中断统一调用了 `stopAndDisconnect`，导致正常松手也必须重连。1.15.3 改为优先发送停止示教、轨迹缓停，清除尚未发送的运动，保留 TCP 会话；确认停稳前锁住所有运动、夹爪、录制及回放入口。

停稳屏障需要：

- 控制器用 `arm_slow_stop:true` 确认 `set_arm_slow_stop`；不接受其他布尔字段代替。
- 缓停确认之后发出的规划查询返回 `type:none`。
- 至少三帧不同序号的新关节反馈，在 300ms 窗口中相对固定起始帧的六轴变化均不超过 0.03°。不能将连续小幅漂移当成停稳。
- 最新关节反馈不超过 250ms，规划回复不超过 1 秒；位置、安全状态及故障检查仍有效。

缓停确认超过 5 秒、停稳超过 8 秒或状态异常时，发送停止并断开，显示具体原因。正常到位和正常松手确认完成均保持连接。切后台、明确断开、通信发送失败等仍会断开；步进中断继续使用原先的停止并断开流程。断联后不会重放未确认指令。

停止命令的优先级会清除待发送运动；正在发送的命令先完成，然后按 TCP 顺序发送停止，不会在停止之后再发送旧目标。单个发送阻塞仍由独立看门狗关闭连接。回归使用 localhost 模拟控制器验证队列取消、同会话停止确认、后续查询与新运动可用；不连接实体机械臂执行测试。

官方字段来源：[运动指令集](https://develop.realman-robotics.com/robot4th/json/motionConfig/) 的轨迹缓停和查询当前规划类型。

本版还包括：

- 复位和联动都使用顶部速度设置（1～30%），默认 5%；移除单独的 5%/3% 上限。联动单次各轴最多 10° 的范围仍保留。
- 夹爪张开、闭合按钮加大，垂直排列。
- 三维图在真实关节原点加 J1～J6 标签和引线：J2/J3/J5 为绿色“弯曲”，J1/J4/J6 为蓝色“旋转”。标签随关节姿态和观察相机投影更新，重叠原点的标签错开，不能触发运动。模型本体几何保持不变。

软件测试不能代替现场运动验证，模型标签不提供碰撞判断。

# 1.15.2 关节联动、夹爪简化和保存姿态复位

当前行为以 [1.15.3 更新](RELEASE_CONNECTION_FIX.md) 为准：复位与联动速度由顶部 1～30% 设置；正常松手确认停稳后保留连接。以下记录为 1.15.2 初始实现。

基于 1.15.1 回退；撤下 1.16 的三维目标控制及 1.17 的奇异脱离辅助。只读三维预览、夹爪检测恢复、动作库和已有网络/松手停止修复均保留。versionName 为 1.15.2，versionCode 为 28，以同签名覆盖更新已安装的 1.17.0，避免卸载清除用户数据。

## 夹爪

操作区只提供“张开夹爪”“闭合夹爪”，去除目标开口滑块和“移动到位置”，并移除公开 `gripperPosition` 桥接入口。已有动作库内的夹爪位置节点仍可回放，数据不会被删除。常接夹爪检测、状态读回、诊断及必要时显式“启用并张开夹爪”的恢复入口继续保留。

## 保存复位姿态

静止时点击“保存复位”，将当前反馈的六个关节角及时间写入本机 `saved_reset_pose_v1`，重启后仍保留。只保存机械臂姿态，不保存或改变夹爪开关状态。点击保存不产生运动；再次保存会覆盖先前的复位姿态。

先保存后才能“按住复位”。持续按住返回保存的六轴姿态，速度不超过页面速度与 5% 的较小值。已在目标 ±0.05° 内时提示无需运动。复位为关节空间运动，工具路径不保证直线；需要操作者确认整条路径空间并持续按住。录制、回放、夹爪动作或其他手动运动期间不能保存或启动复位。

复位开始前检查当前姿态和目标都在最新软件安全区内；执行期间检测安全区变化、关节偏离起止范围 ±0.25°、状态过期和故障。指令确认超时 5 秒，总执行超时 120 秒。到位必须有 movej 接收确认、device=0 的成功事件，以及事件后两帧不同序号的六轴反馈均在目标 ±0.05° 内。损坏/旧格式保存数据不能转换为全零目标；不再提供全零“按住回零”按钮。

## J2/J3/J5 联动试用

单轴标识旁提示 J2/J3/J5“弯曲”、J1/J4/J6“旋转”。在“关节调整”页额外提供联动 − / ＋：三根弯曲轴按 1:1:1 同步减小或增大角度，J1/J4/J6 保持开始时角度。整体是否呈现收拢或展开取决于当前构型，因此按钮明确显示角度正负方向。

每次按住执行一条有限的 [movej 关节运动](https://develop.realman-robotics.com/robot4th/json/motionConfig/)；最多三轴各 10°，速度不超过页面速度与 3% 的较小值。按最近关节限位等量缩小幅度，并额外预留 0.05°，不足 0.5° 时拒绝启动。完成整段后必须松开再按才能继续，没有自动排队、循环、CANFD 透传或关节示教指令的竞争。

这是一组固定比例关节联动，不保持夹爪位置、朝向，不作碰撞判断，暂不支持在动作录制期间使用。执行中另外检测三轴进度差不超过 0.5°、其他关节保持原位 ±0.25°。指令确认超时 5 秒，总执行超时 30 秒。到位屏障同复位。

## 按住与停止

复位和联动都要求原生 `ManualTouchGuard` 检测到真实单指持续按压。网页每 500ms 发送心跳；两种功能始终启用 1.5 秒保护，独立于可关闭的普通点动看门狗。旧的空闲状态帧不能取消本地按住，也不能吞掉松手停止。

松手中断、触摸取消、失焦、切后台、立即停止、指令拒绝和反馈异常会发送停止并断开连接，清除待发送运动；继续需重新连接。正常到位后连接保留。停止指令遇到物理网络故障不保证送达，实体急停须保持可用。

原有动作、连接地址、软件限位和夹爪开关录制逻辑不变。软件回归测试覆盖姿态持久化、限位与目标校验、真实按住联动的网页行为、旧状态帧、强制心跳、到位事件与独立反馈、超时及互锁；新增控制尚需现场实机运动验证。
